# 页面与交互

本文描述当前页面结构与操作行为。实际安装、截图和检查结果见 [验证记录](validation.md)；历史版本的界面保留在对应验证归档中。

## 视觉与文字

界面使用 Jetpack Compose 与官方 Material 3 Expressive 组件，统一字体角色、图标和控件样式。主题内统一设置明暗模式、Monet 动态取色和固定配色；明暗可跟随系统，也可固定为浅色或深色。语言可选跟随系统、简体中文和 English。

普通标签、标题和统计数字使用同一套 Material 字体；地址和密钥使用等宽字体。常规页面保留操作、状态和结果，协议范围等说明放在帮助入口。错误只说明已知失败及可执行的下一步。

Codex 与 DeepSeek 使用各自品牌标记，自定义兼容来源使用服务器图标。素材来源见 [第三方说明](third-party.md)。

## 导航

底部导航包含四个目的地：

| 页面 | 主要内容 |
| --- | --- |
| 共享 | 模型共享开关、本机/局域网 API 地址、访问密钥、接入说明、最近请求 |
| 模型 | 供应商列表及二级模型，统一添加、配置、登录、获取模型和启停 |
| MCP | 远程连接、工具选择、MCP 共享、连接地址与最近调用 |
| 设置 | 主题、语言、代理、端口、备份及应用信息 |

统计从「模型」首页右上角进入，不占主导航位置；最近请求、供应商和模型仍可打开对应统计。进入统计后隐藏底部导航，返回恢复来源页面和层级。

模型与 MCP 的首页不显示返回箭头；进入供应商模型或 MCP 连接详情后显示返回箭头，并隐藏底部导航。设置作为主页面保留底部导航。MCP 通知直接打开 MCP 首页，不叠加第二个 Activity。

## 模型共享

总开关反映前台服务的实际状态。配置供应商和模型与启动监听分别操作；尚无可用模型时提供对应配置入口。关闭共享停止监听并释放服务资源，地址选择不改变服务的监听范围。

地址卡片区分两种接入方式：

| 方式 | 地址与选择规则 |
| --- | --- |
| 本机 | 使用 `127.0.0.1`，供同一手机上的其他应用接入 |
| 局域网 | 显示手机当前网络的 IPv4 地址；有多个地址时可切换，并标明网络类型和接口 |

局域网优先列出 Wi-Fi、有线及未分类接口；VPN、蜂窝地址按需展开。页面和运行中的服务定期刷新地址，已选地址消失后选择剩余候选。选择仅影响展示和复制，同一模型服务共用端口、共享密钥与模型路由。

「接入说明」展示当前 Base URL、模型名称填写方式及各端点的完整地址。没有可用局域网地址时，不提供不存在的完整地址。接口及供应商兼容范围见 [API 文档](api.md)。

新访问密钥带 `sk-` 前缀，默认隐藏随机部分，可显隐和复制；重置前说明旧密钥将失效。首页有请求记录时显示最近两条，点击进入统计详情，「全部」打开请求列表。

## 供应商与模型目录

在「模型」首页点击添加供应商，先选择来源，再填写相应配置。DeepSeek 需要 API Key；自定义 OpenAI 兼容来源允许 HTTP/HTTPS，无认证服务可留空 Key。字段错误定位到对应输入框。密钥默认隐藏，敏感剪贴板标记与加密存储由实现处理。

Codex 使用独立设备代码登录流程。新供应商先保存再登录；授权成功后打开模型选择并读取订阅目录。供应商的二级模型页和编辑页均可获取模型；未登录的 Codex 显示登录入口。编辑名称不清除已有授权。

模型目录支持获取、取消、筛选和多选，也可手动填写 ID。获取失败显示错误并允许重试，空目录有对应状态。目录请求使用当前上游代理，读取订阅凭据及刷新令牌在 IO 工作中完成。重新登录清除旧账号的目录选择，保留手动输入。

保存供应商时一起保存选中的模型，随后停留在该供应商的模型页：同一供应商/上游模型不会重复创建，共享名称冲突时加后缀，已有路由继续保留。删除供应商前说明会一并删除其模型路由。

## 按供应商管理模型

「模型」一级展示已配置供应商、品牌图标、地址或 Codex 登录状态、模型数、启用数与供应商开关，包括尚无模型的供应商。点击供应商进入二级，不再单设重复的供应商主页面。

二级展示该供应商已添加的共享模型。每项对应一条路由：客户端使用共享模型名 `alias`，手机转发到供应商的 `upstreamModel`。两个名称相同时不重复显示。搜索匹配两者，并可按全部、已启用、已停用筛选。

供应商开关和模型开关独立保存。停用供应商会从共享 API 中移除其模型，但保留各模型的开关；再次启用供应商后沿用原设置。页面数量表示配置状态，不作为上游连通性结果。

二级顶栏提供编辑供应商、手动添加模型和更多菜单；更多菜单包含供应商统计，已登录 Codex 可重新登录。页面中的「获取模型」使用该供应商配置读取目录。模型行可编辑共享名、上游 ID，或查看对应请求。已有共享名称不会因页面分组而重命名。

## 统计与请求

统计从模型首页右上角打开，使用「概览 / 请求」分段切换，日期范围为今天、7 天、30 天和全部保留记录。概览展示请求数、已记录 Token、成功率、平均耗时和趋势，可按供应商或模型汇总并进入对应请求。

从共享页请求、供应商或模型入口进入时，带上对应筛选，默认查看全部保留记录；从统计概览下钻则保留当前日期范围。请求列表可搜索供应商、共享模型名和上游 ID，按成功、失败或中断筛选。

详情展示时间、耗时、端点、供应商和上游模型、流式状态、HTTP 状态、错误码及 Token 明细。HTTP 200 但流未完成仍记为中断。输入缓存和推理输出作为明细展示，不重复加入总数。

本机保存最近 1,000 条请求元数据，停止共享或重启后仍可查看。统计基于这些记录；未知 Token 显示「—」，与真实的 0 区分，不推算订阅剩余额度。清空操作同时清除记录及其统计，执行前有确认。存储失败保留具体错误及重试入口。

## MCP

MCP 首页管理远程连接、独立共享开关，并显示最近调用；连接详情提供本机/局域网地址、MCP 访问密钥、获取工具和工具选择。主页面与连接详情的共享开关控制同一个 MCP 服务。

「添加连接」打开可滚动的预设列表，提供 Microsoft Learn、OpenAI Docs、Context7、GitHub 和「自定义连接」。Learn 与 OpenAI Docs 点选后直接添加；Context7 填 API Key，GitHub 填个人访问令牌，表单提供官方获取入口。预设已带服务地址与认证方式，无需重复输入。

保存预设后进入连接详情，自动获取并显示工具目录。读取失败时保留已保存连接，显示错误并可点击「获取工具」重试。相同地址和令牌已有连接时直接打开，不重复创建；同一地址使用不同令牌可以分别添加。

自定义连接继续填写名称、完整 HTTP(S) MCP URL，以及无认证或 Bearer 认证；后续编辑预设连接也使用同一个完整编辑器。获取工具后可选择允许共享的工具；连接开关与工具选择分别保存。每个连接有独立 `/mcp/<connectionId>` 路径，MCP 端口和共享密钥与模型服务分开。添加连接不会自动启动共享。

MCP 与模型页面复用共享开关、地址选择和密钥操作控件，同类文字与状态含义保持一致。协议、端口、地址路径和密钥仍各自取自对应服务。兼容范围和配置步骤见 [MCP 文档](mcp-roadmap.md)。四项预设与凭据依据见 [远程 MCP 预设](mcp-presets.md)；GitHub PAT 配置及手机运行时分工见 [在手机上使用 MCP](android-mcp.md)。当前提供精选静态预设，在线 Registry 搜索、OAuth 与本地 stdio 运行时仍待实现。

## 设置

| 分组 | 选项 |
| --- | --- |
| 偏好 | 主题（明暗、动态取色、固定配色）、语言 |
| 连接 | 模型监听端口、上游代理、重置模型共享密钥 |
| 备份 | 导出和导入 `.ppbackup` |
| 应用 | 系统后台运行设置、使用说明、版本 |

「主题」打开可滚动的底部面板，依次选择明暗、动态取色和固定配色，顶部「完成」关闭面板。固定配色提供森林绿、海蓝、紫晶、玫瑰、琥珀；点击后立即应用并关闭动态取色。开启动态取色会保留上次固定配色，关闭后恢复该选择。设置行摘要显示实际明暗与取色方式。

Android 12+ 可使用动态取色；Android 8–11 显示固定配色，动态选项标注版本要求并禁用。旧配置沿用原有明暗和取色偏好，新增固定配色默认森林绿；所选配色随应用偏好进入加密备份。

模型端口在模型服务停止后修改；MCP 端口和密钥在 MCP 菜单中管理。上游代理可跟随系统或指定 HTTP/SOCKS5，覆盖模型目录、生成、App 内 Codex 授权/刷新和远程 MCP 请求；外部登录浏览器使用自身网络配置。

备份导出需要口令，可选择包含 Codex 登录状态。导入需先停止模型与 MCP 共享，选择文件、解锁并检查预览后恢复；默认保留目标手机的端口、共享密钥和上游代理，也可选择恢复这些连接设置。恢复成功后不自动开启共享。
