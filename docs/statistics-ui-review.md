# 统计页 UI 审查

日期：2026-11-25。范围为共享 → 统计概览 → 供应商/模型明细 → 请求详情，及系统字体放大后的同一流程。

## 起点与依据

本次起点是用户在对话中提供的当前共享页截图。它显示共享开关、地址、访问密钥、大号「今日用量」卡以及最近请求连续堆叠。原源码中的「今日用量」标题采用 titleMedium，其他卡片采用 labelMedium；「未提供」与数字共同使用 headlineSmall。问题来自字体角色和信息层级不一致，未发现该卡单独引入其他字体文件。

参考 [CC Switch 的统计组织方式](statistics-reference.md)，将分析功能放入独立底部「统计」入口；共享页集中显示连接与共享控制。继续使用官方 Material 3 Expressive 组件、Monet 和系统字体。

## 修改与核验路径

| 步骤 | 修改 | 当前核验状态 |
| --- | --- | --- |
| 1. 共享 | 移除大用量卡，最近请求仅有记录时显示最近两条；地址、访问密钥和共享卡标题统一角色。 | 等待本轮截图 |
| 2. 统计概览 | 独立导航，概览/请求分栏；今天/7天/30天/全部；四项指标采用同一数字样式，缺失值为「—」。 | 等待本轮截图 |
| 3. 趋势与明细 | 请求/Token 单指标趋势；时间段可点选或前后切换；供应商/模型明细可进入对应请求。 | 等待本轮截图 |
| 4. 请求与详情 | 保留搜索、结果筛选、耗时、HTTP 状态和 Token 明细；中断与 HTTP 状态分别显示。 | 等待本轮截图 |
| 5. 大字体 | 跟随系统字体，放大时概览改单列；时间范围可以横向滚动；长模型名可换行。 | 等待 320dp、1.5 倍实际运行截图 |

截图审查与 Compose 布局断言能检查当前屏幕的截断、重叠、选中状态和可达性；它们不能代替 TalkBack 全流程或完整无障碍认证。本轮设备、结果与证据将在 [验证记录](validation.md) 和 [截图目录](../artifacts/screenshots/v0.1.9/README.md) 中记录。
